# Blockchain Technology (BITS F452) - Term Project (Option 1)

## Problem Statement

Design and build a fully functional Decentralized Application (DApp) that replaces a traditional centralized
system in a domain of the team's choosing (e.g., hospital records, government records, supply chain,
education, real estate, voting, etc.). The application's core business logic must be implemented as one or
more smart contracts deployed on a blockchain testbed, with full-fledged front-end and back-end
development.

## Core Requirements

- Choose a real-world domain
- Identify the actors/stakeholders
- Design and implement smart contract(s)
- Deployment on a real blockchain testbed
- Build a front-end DApp and a backend
- Identify evaluation parameters and demonstrate the evaluation of the project
- Justify your design decisions
